# 🌱 GreenMindAI: Scan. Sort. Sustain.

GreenMindAI is a tech-driven waste management platform that empowers individuals, waste workers, and local bodies to track, segregate, and recycle waste efficiently using AI-powered tools and community incentives.

> 🧠 **Finalist at Hack Vortex, Clash of Code 2.0, and T-Hacks**  
> 🚮 **10K+ kg waste reported in pilot phase**  
> 🤝 **Partnered with 3+ Municipal Corporations**

---

## 🚀 Problem Statement

**Theme**: Environment  
**Category**: Software  
**Hackathon PS**: Waste Management  

GreenMindAI aims to tackle critical waste management challenges:

- Environmental pollution, food & water contamination  
- Low awareness of carbon footprints and climate impact  
- Inefficient municipal waste collection systems  
- Economic and social losses due to poor segregation  
- Lack of motivation for eco-friendly behavior

---

## 💡 Core Features

### 📸 AI-Based Waste Detection
- Users upload images of waste via the app
- ML model classifies waste as organic or inorganic
- Geo-tagging and automated categorization

### 🗺️ Real-Time Waste Mapping
- Neon + Google Maps API integration  
- View city-wide waste hotspots and collection routes

### 🏆 Reward System
- Cashback, coupons, and vouchers for users
- Incentives for verified waste collectors

### 🔢 Carbon Footprint Tracker
- Users get real-time carbon reduction scores
- Rewards for low-carbon activities

### 🔁 Waste Distribution Model
- Organic waste sent to composting units  
- Inorganic waste sent to recycling centers  
- Collaboration with industries for waste buyback

### 👷 Employment Portal
- Formal job platform for trash pickers  
- Fair wages and dignity in labor  
- Govt. subsidies for verified work
